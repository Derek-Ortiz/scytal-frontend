# Seguridad

## Reportar una vulnerabilidad

Informa las vulnerabilidades de forma privada mediante GitHub Security Advisories:

1. Abre la sección **Security** del repositorio.
2. Selecciona **Report a vulnerability**.
3. Describe el impacto, los pasos para reproducirlo y cualquier mitigación conocida.

No abras un issue público para detalles de una vulnerabilidad activa. Incluye únicamente
la información necesaria para evaluar y corregir el problema.

## Alcance

Reporta vulnerabilidades relacionadas con el frontend, su integración con la API, el manejo
de autenticación, la descarga de reportes, el preprocesamiento de plantillas y la exposición
de datos de simulación.

Confirmaremos la recepción, analizaremos el alcance y coordinaremos una corrección cuando
sea posible. Las fechas y responsables deben acordarse en el canal privado de GitHub.
